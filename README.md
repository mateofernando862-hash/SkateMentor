# SkateMentor

SkateMentor es una propuesta web para conectar a personas que practican skate
urbano con mentores, puntos de encuentro y comunidades locales. El objetivo es
hacer el deporte más accesible, seguro y colaborativo.

## Ejecutar

No requiere dependencias ni proceso de compilación:

```bash
python3 -m http.server 4173
```

Después abre `http://localhost:4173`.
